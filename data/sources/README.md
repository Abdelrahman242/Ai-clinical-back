# data/sources/

الملفات هنا بقت منظمة **فولدر لكل مشروع**، مش فولدر واحد فيه كل حاجة:

```
data/sources/<project_id>/document1.pdf
data/sources/<project_id>/document2.txt
```

`<project_id>` هو نفس الـ ID اللي بيظهر في رابط المشروع في الفرونت اند
(مثلاً `.../projects/994ccf352bba40d38de6e7bf5d928538/...`) — أو تقدر تشوفه
في صفحة تفاصيل المشروع نفسها.

**مفيش حاجة تانية لازم تعملها.** بمجرد ما تحط ملف PDF أو TXT جوه فولدر
المشروع، السيرفر (background scanner شغال طول الوقت) هيكتشفه لوحده خلال
ثواني (شوف `AUTO_INGEST_INTERVAL_SECONDS` في `.env`، الافتراضي 15 ثانية)،
ويعمله تسجيل + فهرسة (embedding) تلقائيًا من غير أي ضغطة زرار.

لو عايز تتأكد إنه اتفهرس، افتح صفحة المشروع في الواجهة (قسم "مستندات
النظام") وهتلاقي حالته اتغيّرت لـ "متفهرس ✅".
